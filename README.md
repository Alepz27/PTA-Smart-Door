# PTA Smart DoorESP32-based access-control project developed for PTA. It combines RFID, AS608 fingerprint verification, a 16x2 I2C LCD, relay-driven solenoid lock, touch exit, Blynk and Telegram monitoring.![Cirkit Designer wiring diagram](docs/Smart-Door-Cirkit-Designer-Wiring.png)## Project Evidence- [Arduino firmware](firmware/FULL_CODE_SmartDoor_PTA1.ino) — public-safe version; Wi-Fi, Blynk and Telegram credentials are placeholders.- [Proteus simulation project](docs/Litar%20simulasi%20Smart%20Door.pdsprj)- [Proteus RFID test cases](docs/PROTEUS_UID_TESTS.md)- [Cirkit Designer project](https://app.cirkitdesigner.com/project/c76d481d-00aa-41fe-8f70-778ca7574145)## System Architecture~~~mermaidflowchart LR  User[Authorised user] --> RFID[RC522 RFID]  User --> FP[AS608 fingerprint]  RFID --> ESP32[ESP32]  FP --> ESP32  Blynk[Blynk] <--> ESP32  Telegram[Telegram] <--> ESP32  ESP32 --> LCD[16x2 I2C LCD]  ESP32 --> Relay[Relay]  Relay --> Lock[Solenoid lock]~~~## Verified ESP32 Pin Map| Module | ESP32 pins || --- | --- || RC522 RFID | SS GPIO 5, RST GPIO 2, SCK GPIO 18, MISO GPIO 19, MOSI GPIO 23 || AS608 fingerprint | RX GPIO 16, TX GPIO 17 || I2C LCD | SDA GPIO 21, SCL GPIO 22; address 0x27 || Relay / solenoid control | GPIO 26 || Touch exit | GPIO 27 || Green LED | GPIO 25 || Red LED | GPIO 33 || Buzzer | GPIO 32 |## Implemented Features- RFID and fingerprint authentication- RFID and fingerprint enrolment- Local user database using ESP32 Preferences- Access logs, buzzer and LED feedback- Five-second automatic door re-lock- Blynk dashboard and Telegram notifications- Multi-Wi-Fi retry logic and sensor recovery handling## Proteus DemonstrationUse the UID test document to demonstrate both access-granted and access-denied behaviour in the Proteus simulation.## SecurityDo not publish Wi-Fi passwords, Blynk tokens, Telegram tokens or chat IDs.
